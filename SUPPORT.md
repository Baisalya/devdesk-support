# Supporting DevDesk

Thank you for using DevDesk! This repository is dedicated to user support, bug reporting, and feature requests.

## How to Get Support

1. **Check the Privacy Policy**: Many common questions about data handling are answered in our [Privacy Policy](https://baisalya.github.io/devdesk-support/privacy-policy.html).
2. **Search Existing Issues**: Your question or bug might have already been reported.
3. **Open a New Issue**: Use one of our structured templates to provide the necessary information.

## Reporting Issues

### Bug Reports
If you find a reproducible bug, please use the [Bug Report Template](https://github.com/Baisalya/devdesk-support/issues/new?template=bug_report.yml). Be sure to include your platform (Android/Windows) and app version.

### Feature Requests
We welcome suggestions for new tools or improvements! Please use the [Feature Request Template](https://github.com/Baisalya/devdesk-support/issues/new?template=feature_request.yml).

### Privacy Questions
For general questions about how DevDesk handles your data, use the [Privacy Question Template](https://github.com/Baisalya/devdesk-support/issues/new?template=privacy_question.yml).

## Data Safety Warning

**IMPORTANT**: This is a public repository. Every issue you open and every comment you make is visible to the entire internet.

**NEVER POST:**
- API Keys or Access Tokens
- Passwords or Credentials
- Authentication Headers (e.g., `Authorization: Bearer ...`)
- Private API Payloads or Request Bodies
- Personal Data (Emails, Names, Phone Numbers)
- Proprietary Source Code
- Confidential Workspace Content

If you mistakenly post sensitive information, edit or delete your comment immediately and rotate any exposed credentials.
