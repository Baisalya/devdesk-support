Privacy Policy

Effective: 24 July 2026 | Last updated: 24 July 2026

DevDesk is offline-first by design. We believe your developer tools should respect your privacy and keep your data local.

1. Introduction

This Privacy Policy explains how DevDesk, published by Baisalya, processes and protects your information on Android and Windows. DevDesk is an offline-first developer toolbox.

DevDesk has no user account system, advertising, analytics, telemetry, cloud synchronization, or DevDesk-operated backend. Baisalya does not receive your usage data or locally stored content.

2. Information DevDesk Processes

DevDesk stores information only to provide features you choose to use. Application records are stored in the app's private local data area on your device.

  • Local Workspace Content: Markdown documents, notes, snippets, favorites, and tool history.
  • Preferences: Appearance settings and privacy policy acceptance records.
  • Protected Secrets: API keys and tokens you mark as secrets are stored using platform security (Android Keystore or Windows DPAPI).

3. Local File Processing

DevDesk reads a file only after you explicitly select it through the platform's file picker. It does not request broad storage access. Windows uses paths selected by you, and Android uses system-provided document access.

4. API Testing and Network Requests

DevDesk sends network requests only when you initiate them:

  • API Tester: Sends requests to the URL you provide and receives responses directly. No DevDesk proxy is used.
  • External Content: Fetching public GitHub metadata or files for comparison/import features.
  • Link Validation: Sending HEAD requests to validate URLs you provide.

The destination service receives your IP address and the request details. Review the destination's privacy policy before sending sensitive data.

5. Data Security

Protected secrets are excluded from DevDesk backups by default. We use platform-specific encryption to guard sensitive values. However, no security control is absolute. Malware or physical access to an unlocked device may expose data.

6. Retention and Deletion

All data remains on your device until you delete it, use the "Clear All Data" feature in Settings, or uninstall the app. DevDesk has no online account to delete.

7. Children's Privacy

DevDesk is a professional developer tool and is not directed to children under 13.

8. Contact and Privacy Questions

Privacy questions may be submitted through the DevDesk Support repository’s Privacy Question form. Do not include credentials, personal data, or proprietary source code in a public issue.

9. Security Vulnerability Reporting

Do not report security vulnerabilities in a public GitHub issue. Use DevDesk’s private vulnerability reporting channel: Report Security Vulnerability.
