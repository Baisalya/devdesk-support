# DevDesk Support

DevDesk is an offline-first developer workspace for Android and Windows. This repository contains public support resources and does not contain the DevDesk application source code.

> [!WARNING]
> **Never post API keys, passwords, access tokens, authentication headers, private request bodies, environment files, personal information, proprietary source code, or confidential workspace content in a public issue.**
>
> All issues in this repository are public and visible to everyone.

## Resources

- [Privacy Policy](https://baisalya.github.io/devdesk-support/privacy-policy.html)
- [Support Homepage](https://baisalya.github.io/devdesk-support/)

## Security

Do not report security vulnerabilities in a public GitHub issue. Use DevDesk's private vulnerability reporting channel:

- [Report a Security Vulnerability](https://github.com/Baisalya/devdesk-support/security/advisories/new)

## About this Repository

The primary DevDesk source repository is private. This support repository does not provide application source code.
