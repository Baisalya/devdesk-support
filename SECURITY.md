# Security Policy

## Reporting a Vulnerability

**Do not disclose security vulnerabilities publicly.**

If you discover a potential security vulnerability in DevDesk, please report it privately through GitHub's private vulnerability reporting feature:

[Report a Security Vulnerability](https://github.com/Baisalya/devdesk-support/security/advisories/new)

### What to include
- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

### What NOT to include in public issues
- Do not include exploits, tokens, credentials, or sensitive logs in public GitHub issues.
- Normal bugs and feature requests should be submitted via the standard issue templates.

## Supported Versions

We generally support the latest stable release of DevDesk. Please ensure you are using the most recent version before reporting a vulnerability.
